Documentation & Version History

  • v3.1.0 (Current)

    Moved the AI call to a secure Cloudflare Pages Function so no API key is exposed in the browser. Enabled Google Search grounding for real web results, added output escaping, link validation, and clean timeout handling.

  • v2.0.0

    Major UI overhaul. Transitioned AI response to structured JSON for faster generation to prevent 524 timeouts. Added advanced filtering and sorting. Redesigned result cards with native links. Improved mobile responsiveness and counter alignment.

  • v1.1.0

    Migrated to secure serverless API, added "Anytime" date toggle, added basic error handling.

  • v1.0.0

    Initial beta release with direct API integration.
